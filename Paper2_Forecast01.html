Question 1: Pizza Order Calculator

📊 10 marks⏱️ 15 mins📂 Q01FINISHED.py

A pizza restaurant calculates order totals. The base prices depend on pizza size.

Prices:

SizeCodePrice
SmallS£6.99
MediumM£9.99
LargeL£12.99

Additional rules:

  • Extra toppings cost £1.50 each
  • Orders of 3 or more pizzas get 10% off the total
  • Delivery adds £2.50 (Y/N input)

Requirements:

  • Store topping price and delivery charge as constants
  • Input: size code, number of extra toppings, quantity, delivery (Y/N)
  • Calculate total and display to 2 decimal places
SizeToppingsQtyDeliveryOutput
M21N£12.99
L13Y£41.62
S02N£13.98

📖 PLS: Data Types (p.5), Selection (p.7), Formatting (p.12)

Constants: TOPPING_PRICE = 1.50 DELIVERY_CHARGE = 2.50 Input: size = input("prompt").upper() toppings = int(input("prompt")) Selection: if size == "S": price = 6.99 elif size == "M": Discount: total = total * 0.9 (10% off) Format: "£{:.2f}".format(total)
⚠️ IN THE REAL EXAM: No hints! Find this in your PLS document.

Mark Scheme (10 marks)

PointDescriptionMarks
1Constants for topping/delivery prices(1)
2Input size with .upper() conversion(1)
3Input toppings as integer(1)
4Input quantity as integer(1)
5Selection for size (S/M/L prices)(1)
6Calculate pizza + toppings cost(1)

8Apply 10% discount for qty >= 3(1)

10Correct output formatted to 2dp(1)

Examiner's Comments

✗ Common Errors
  • Applying discount before multiplying by quantity
  • Adding delivery before applying discount (delivery shouldn't be discounted)
  • Forgetting to multiply toppings by quantity
  • Using qty > 3 instead of qty >= 3
💡 Tip

Order of operations: (base + toppings) × quantity → apply discount → add delivery. Test with L, 1 topping, 3 pizzas, delivery: (12.99+1.50)×3 = 43.47 × 0.9 = 39.12 + 2.50 = £41.62

📋 Model Answer
TOPPING_PRICE = 1.50
DELIVERY_CHARGE = 2.50

size = input("Enter size (S/M/L): ").upper()
toppings = int(input("Extra toppings: "))
quantity = int(input("How many pizzas: "))
delivery = input("Delivery? (Y/N): ").upper()

# Get base price
if size == "S":
    base = 6.99
elif size == "M":
    base = 9.99
else:
    base = 12.99

# Calculate subtotal
pizzaCost = base + (toppings * TOPPING_PRICE)
total = pizzaCost * quantity

# Apply bulk discount
if quantity >= 3:
    total = total * 0.9

# Add delivery
if delivery == "Y":
    total = total + DELIVERY_CHARGE

print("Total: £{:.2f}".format(total))

Formulas:

  • Fahrenheit to Celsius: C = (F - 32) × 5/9

Requirements:

  • Input the conversion direction (C for Celsius→Fahrenheit, F for Fahrenheit→Celsius)
  • Validate: Celsius cannot be below -273.15 (absolute zero)
  • Validate: Fahrenheit cannot be below -459.67 (absolute zero)

TempDirectionOutput
100C212.0°F
32F0.0°C
-300CInvalid temperature
-500FInvalid temperature

📖 PLS: Conversion (p.5), Operators (p.6), round() (p.9)

Float input: temp = float(input("prompt")) Division: Use / for decimal division Rounding: round(value, 1) for 1 decimal place Selection: if direction == "C": if temp >= -273.15: result = (temp * 9/5) + 32 Output: print(str(result) + "°F")
⚠️ Check your boundary values carefully!

Mark Scheme (10 marks)

PointDescriptionMarks
1Input temperature as float(1)
2Input direction with case conversion(1)
3Celsius validation (>= -273.15)(1)
4Fahrenheit validation (>= -459.67)(1)
5Correct C to F formula(1)
6Correct F to C formula(1)
7Round to 1 decimal place(1)
8Display with correct unit (°C or °F)(1)
9Invalid temperature message(1)
10All test cases correct(1)

Examiner's Comments

✗ Common Errors
  • Using integer division // instead of /
  • Getting the formula wrong: (C × 9) / 5 vs C × (9/5) - both work but parentheses matter
  • Forgetting that absolute zero is NEGATIVE, so validation is >= not <=
  • Mixing up which unit to display
💡 Tip

Test with known values: 0°C = 32°F, 100°C = 212°F. These are easy to verify!

📋 Model Answer
temp = float(input("Enter temperature: "))
direction = input("Convert from (C/F): ").upper()

valid = True
result = 0.0

if direction == "C":
    if temp >= -273.15:
        result = (temp * 9/5) + 32
        result = round(result, 1)
        print(str(result) + "°F")
    else:
        valid = False
elif direction == "F":
    if temp >= -459.67:
        result = (temp - 32) * 5/9
        result = round(result, 1)
        print(str(result) + "°C")
    else:
        valid = False
else:
    valid = False

if not valid:
    print("Invalid temperature")

Question 4: Dice Game Score Calculator (Parsons)

📊 15 marks⏱️ 20 mins📂 Q04FINISHED.py

A dice game rolls two dice. The score depends on the result:

  • Double 6: Score = 25 points
  • Any other double: Score = total × 2
  • Not a double: Score = total

The game plays 3 rounds and totals the score.

RoundDice 1Dice 2Round Score
16625
23312
3426
Total43

Rearrange the lines. DO NOT change indentation!

📖 PLS: random.randint() (p.13), for loop (p.7), Selection (p.7)

Import: import random For loop: for round in range(3): Random: dice1 = random.randint(1, 6) Double check: if dice1 == dice2: Nested: if dice1 == 6: score = 25 else: score = (dice1 + dice2) * 2
⚠️ NEVER change indentation in Parsons problems!

Mark Scheme (15 marks)

PointDescriptionMarks
1import random at top(1)
2Initialise total = 0(1)
3for loop with range(3)(1)
4Roll dice1 inside loop(1)
5Roll dice2 inside loop(1)
6Check for double(1)
7Check for double 6(1)
8Score = 25 for double 6(1)
9Score = total × 2 for other double(1)
10Score = total for non-double(1)
11Add to total inside loop(1)
12Print total after loop(1)
13-15Program runs correctly(3)

Examiner's Comments

✗ Common Errors
  • Checking for double 6 before checking if it's a double at all
  • Adding to total outside the loop (only adds last round)
  • Print statement inside the loop (prints 3 times)
  • Changing indentation levels
💡 Tip

The nesting structure is: for loop → if double → if double 6 / else other double → else not double. Trace through with sample dice rolls on paper.

📋 Model Answer
import random
total = 0
for round in range(3):
    dice1 = random.randint(1, 6)
    dice2 = random.randint(1, 6)
    print("Dice:", dice1, dice2)
    if dice1 == dice2:
        if dice1 == 6:
            score = 25
        else:
            score = (dice1 + dice2) * 2
    else:
        score = dice1 + dice2
    print("Round score:", score)
    total = total + score
print("Total score:", total)

Question 5: Employee Payroll Calculator

📊 15 marks⏱️ 25 mins📂 Q05FINISHED.py

A company stores employee data in a file. Each line contains: Name, Hours Worked, Hourly Rate (separated by commas).

File Q05_DATA.txt: Jones,40,15.50 Smith,45,12.00 Brown,38,18.75 Wilson,50,14.25 Taylor,35,20.00

Requirements:

  • Create a function calculatePay(hours, rate) that:
    • Pays normal rate for first 40 hours
    • Pays 1.5× rate for overtime (hours over 40)
    • Returns total pay
  • Read data from file and calculate pay for each employee
  • Write Name and Pay (to 2dp) to Q05_OUTPUT.txt
  • Display total payroll cost

Expected calculations:

NameHoursRatePay
Jones4015.50£620.00
Smith4512.00£570.00

Smith: 40×12 + 5×(12×1.5) = 480 + 90 = £570

📖 PLS: Files (p.8), Functions (p.8), split/strip (p.11)

Function: def calculatePay(hours, rate): if hours <= 40: return hours * rate else: normal = 40 * rate overtime = (hours - 40) * rate * 1.5 return normal + overtime File: for line in file: parts = line.strip().split(",") hours = float(parts[1]) Write: file.write(name + "," + "{:.2f}".format(pay) + "\n")
⚠️ Remember: overtime is hours OVER 40, not all hours!

Mark Scheme (15 marks)

PointDescriptionMarks
1Function def with two parameters(1)
2Check if hours <= 40(1)
3Normal pay calculation(1)
4Overtime calculation (hours-40) × rate × 1.5(1)
5Return statement(s)(1)
6Open and read input file(1)
7strip() and split(",")(1)
8Convert hours and rate to float(1)
9Call function and accumulate total(1)
10-12Functionality (levels)(3)
13-15Programming practice(3)

Examiner's Comments

✗ Common Errors
  • Calculating overtime as ALL hours × 1.5 instead of just overtime hours
  • Using hours > 40 instead of hours <= 40 (off-by-one)
  • Not converting hours and rate to float (they're strings from file)
  • Formatting pay inside the function instead of when writing
✓ Good Practice

Test function independently: calculatePay(40, 10) = 400, calculatePay(45, 10) = 400 + 75 = 475

📋 Model Answer
def calculatePay(hours, rate):
    if hours <= 40:
        return hours * rate
    else:
        normalPay = 40 * rate
        overtimePay = (hours - 40) * rate * 1.5
        return normalPay + overtimePay

totalPayroll = 0.0

inFile = open("Q05_DATA.txt", "r")
outFile = open("Q05_OUTPUT.txt", "w")

for line in inFile:
    parts = line.strip().split(",")
    name = parts[0]
    hours = float(parts[1])
    rate = float(parts[2])
    
    pay = calculatePay(hours, rate)
    totalPayroll = totalPayroll + pay
    
    outFile.write(name + ",£{:.2f}".format(pay) + "\n")

inFile.close()
outFile.close()

print("Total payroll: £{:.2f}".format(totalPayroll))

The array is sorted by Room Number.

Write a program to:

  • Accept a room number from the user to book
  • Search for the room using linear search
  • If found AND available: display booking confirmation and price, mark as unavailable
  • If found but NOT available: display "Room already booked"
  • If not found: display "Room not found"
RoomTypePriceAvailable
101Single£75True
102Double£120False
201Double£120True

else:
