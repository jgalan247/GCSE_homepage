# Assessment Calendar
## GCSE Computer Science (Edexcel 1CP2) - 3 Year Delivery Model

This document provides an overview of all assessments across the three-year course.

---

## Assessment Types

| Type | Description | Frequency |
|------|-------------|-----------|
| **End of Topic Test** | Formal assessment on completed SLR topics | 3-4 per year |
| **Programming Assessment** | Practical coding under timed conditions | 2 per year |
| **Mock Exam** | Full paper under exam conditions | Year 11 only |
| **Smart Revise Quizzes** | Regular low-stakes testing | Weekly |
| **Homework Tasks** | Programming and theory practice | Weekly |

---

## Year 9 Assessment Schedule

| Week | Assessment | Format | Topics Covered | Duration |
|------|------------|--------|----------------|----------|
| 11 | Programming Test 1 | Written + Practical | Variables, I/O, Selection, Iteration, Lists | 60 mins |
| 22 | Programming Test 2 | Written + Practical | Strings, 2D Lists, Functions, File Handling | 60 mins |
| 33 | End of Year Test | Written + Practical | SLR 1 & 2 + All Programming | 90 mins |

### Detailed Assessment Breakdown - Year 9

**Programming Test 1 (Week 11)**
- Section A (20 marks): Short answer questions on programming concepts
- Section B (30 marks): Practical programming tasks
  - Task 1: Input/Output program
  - Task 2: Selection-based program
  - Task 3: Iteration with lists

**Programming Test 2 (Week 22)**
- Section A (20 marks): Theory questions on data structures and subprograms
- Section B (30 marks): Practical programming tasks
  - Task 1: String manipulation
  - Task 2: Function/procedure implementation
  - Task 3: File handling program

**End of Year Test (Week 33)**
- Section A (30 marks): SLR 1 (Systems Architecture)
- Section B (20 marks): SLR 2 (System Software)
- Section C (30 marks): Programming practical
- Section D (10 marks): Extended response

## Year 10 Assessment Schedule

| Week | Assessment | Format | Topics Covered | Duration |
|------|------------|--------|----------------|----------|
| 11 | Data Rep Test 1 | Written | SLR 3.1-3.5 (Binary, Hex, Characters, Images) | 50 mins |
| 18 | Data Rep Test 2 | Written | SLR 3.6-3.7 (Sound, Compression) + Review | 50 mins |
| 25 | Networks Test | Written | SLR 4 (Networks) | 50 mins |
| 33 | End of Year Test | Written + Practical | SLR 3-6 + Programming | 90 mins |

### Detailed Assessment Breakdown - Year 10

**Data Representation Test 1 (Week 11)**
- Section A (15 marks): Binary conversions and arithmetic
- Section B (15 marks): Hexadecimal
- Section C (10 marks): Character encoding
- Section D (10 marks): Bitmap images and calculations

**Data Representation Test 2 (Week 18)**
- Section A (15 marks): Sound representation and calculations
- Section B (15 marks): Compression techniques
- Section C (10 marks): Mixed data representation
- Section D (10 marks): Extended response

**Networks Test (Week 25)**
- Section A (20 marks): Network types, hardware, topologies
- Section B (20 marks): Protocols and layers
- Section C (10 marks): Extended response

**End of Year Test (Week 33)**
- Paper 1 Style (60 marks): SLR 3-6 theory
- Paper 2 Style (30 marks): Programming practical

## Year 11 Assessment Schedule

| Week | Assessment | Format | Topics Covered | Duration |
|------|------------|--------|----------------|----------|
| 11 | Algorithms Test 1 | Written + Practical | SLR 9 + SLR 10.1-10.4 | 60 mins |
| 22 | Algorithms Test 2 | Written + Practical | SLR 10.5-10.8 (Searches, Sorts, Logic) | 60 mins |
| 29 | Paper 1 Mock | Written | Full Paper 1 content | 90 mins |
| 31 | Paper 2 Mock | On-screen | Full Paper 2 content | 120 mins |

### Detailed Assessment Breakdown - Year 11

**Algorithms Test 1 (Week 11)**
- Section A (20 marks): Defensive design and testing
- Section B (15 marks): Computational thinking
- Section C (15 marks): Pseudocode and flowcharts
- Section D (10 marks): Trace tables

**Algorithms Test 2 (Week 22)**
- Section A (15 marks): Search algorithms
- Section B (15 marks): Sorting algorithms
- Section C (10 marks): Efficiency
- Section D (20 marks): Boolean logic and circuits

**Paper 1 Mock (Week 29)**
- Full Paper 1 format (90 minutes)
- All SLR 1-6, 9-11 topics
- Mix of short answer and extended response

**Paper 2 Mock (Week 31)**
- Full Paper 2 format (120 minutes)
- On-screen programming examination
- All programming concepts

## External Examinations

| Paper | Format | Duration | Marks | Weighting |
|-------|--------|----------|-------|-----------|
| **Paper 1** | Written exam | 1 hour 30 mins | 80 marks | 50% |
| **Paper 2** | On-screen exam | 2 hours | 80 marks | 50% |

### Paper 1: Principles of Computer Science
- Multiple choice, short answer, extended response
- Calculators NOT allowed
- All SLR 1-6 and 9-11 content

### Paper 2: Application of Computational Thinking
- On-screen examination using Python
- Pre-release material (issued in advance)
- Program completion and program writing tasks

---

## Ongoing Assessment

### Weekly Smart Revise
- Students complete Smart Revise quizzes on topics covered
- Minimum 3 quizzes per week recommended
- Progress tracked and reported termly

### Homework Assessment
- Weekly homework tasks assessed
- Mix of programming and theory
- Marked for effort and accuracy

### Practical Skills Tracking
- Programming skills checklist maintained
- Regular code review sessions
- Portfolio of programming work
