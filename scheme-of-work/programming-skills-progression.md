# Programming Skills Progression Map
## GCSE Computer Science (Edexcel 1CP2) - 3 Year Delivery Model

This document maps when each programming skill is introduced, developed, and secured throughout the course.

---

## Skill Level Key

| Level | Description | Indicator |
|-------|-------------|-----------|
| **I** - Introduced | First exposure to concept; Teacher-led examples | Can follow examples with support |
| **D** - Developing | Guided practice; Scaffolded tasks | Can complete structured tasks |
| **S** - Secure | Independent application; Problem-solving | Can apply to new contexts |
| **M** - Mastered | Fluent; Can teach others; Exam-ready | Consistently correct under pressure |

## Paper 2 Skills Checklist

Students should be able to independently demonstrate all skills by Paper 2:

### Section A: Reading Code
- [ ] Trace through given code
- [ ] Identify output of code
- [ ] Spot errors in code
- [ ] Explain what code does

### Section B: Completing Code
- [ ] Fill in missing code
- [ ] Fix bugs in code
- [ ] Extend existing programs
- [ ] Add validation to code

### Section C: Writing Code
- [ ] Write programs from scratch
- [ ] Use all programming constructs appropriately
- [ ] Implement algorithms
- [ ] Handle edge cases
- [ ] Use meaningful identifiers
- [ ] Add appropriate comments
